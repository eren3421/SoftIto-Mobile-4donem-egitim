# Chat Uygulaması

Dart, Flutter ve Socket.IO kullanılarak geliştirilmiş basit bir gerçek zamanlı sohbet uygulaması.

## Özellikler

- Gerçek zamanlı mesajlaşma
- Birden fazla kullanıcı sunucuya bağlanabilir
- Mesajlar bağlı olan kullanıcılara gönderilir
- Basit ve hafif bir sunucu yapısı

## Kullanılan Teknolojiler

- Dart
- Flutter
- Socket.IO
