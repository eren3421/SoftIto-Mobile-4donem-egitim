# Araba Galerisi

Deneme2 klasöründeki Flutter örneğini temel alan, üç ekranlı bir araba galerisi uygulaması.

## Ekranlar

- **Ana Sayfa:** Öne çıkan otomobiller ve galeri hizmetleri.
- **Araçlar:** Arama, gövde tipi filtresi, favoriler ve araç detayları.
- **Randevu:** Araç seçerek test sürüşü randevusu oluşturma ve randevuları görüntüleme.

Araç ve randevu bilgileri örnek veridir; uygulama herhangi bir sunucuya veri göndermez.

## Çalıştırma

```sh
flutter pub get
flutter run
```
